Inicio rápido local

  1. Prepara PostgreSQL aislado y ejecuta node scripts/prepare-qori-play-qa.js.
  2. Ejecuta node scripts/preview-qori-play.js. Abre la dirección local que imprime.
  3. Entra como operador demo. Abre Player en otra ventana y confirma su código temporal desde la pantalla registrada.
  4. Escanea el QR o usa su enlace en otro navegador. Acepta el aviso y comienza. Los símbolos de Secuencia aparecen solo en la pantalla.
  5. Consulta métricas. Para reclamar, inicia sesión Customer demo en el navegador del control y autoriza el reclamo.

Un teléfono físico necesita un origen HTTPS de laboratorio alcanzable por ambos dispositivos. El host loopback de la demo solo sirve para ventanas del mismo computador. No se crea un túnel público automáticamente.

URL y SDK

Configura la URL /play/screen/ en un reproductor web compatible. Conserva el almacenamiento de ese perfil: contiene un token limitado a una pantalla, con caducidad de 24 horas.

Ejemplo iframe de cartelería · SDK v1 · Tipos TypeScript

El SDK permite inicializar, suscribir estado, obtener el QR, pausar, reanudar y rotar credenciales del dispositivo. El servidor finaliza las partidas. Nunca envíes puntuaciones ni secretos de integrador desde el Player.

API de servidor

Genera una credencial con play:manage y play:analytics en el panel. Canjéala en POST /api/invoice/v1/oauth/token mediante Client Credentials; se reutiliza el servicio OAuth existente. Administra recursos en /api/play/v1/manage.

Ejemplo ejecutable Node.js. El contrato OpenAPI se puede importar en Postman. Las credenciales se revocan y regeneran desde el panel.

Diagnóstico

Sin juego: comprueba campaña aprobada, horario UTC, pantalla activa y conexión. QR vencido: vuelve a escanear; cada token admite una unión. En cola: espera el turno sin cerrar el control. Sin cupo: no existe promesa de premio. Red caída: se conserva el anuncio en la pantalla y se suspende la participación.

Webhooks y conectores específicos de fabricantes quedan pendientes. No hay compatibilidad certificada con Tizen, webOS o Yodeck. La moderación se realiza mediante el panel Admin, la revocación de apps existente y el bloqueo de juegos configurado en el servidor.
