# Estado de las aplicaciones

Qori Customer se entrega como **portal web** en `/customer/`.

El cliente activo vive en `customer-web/` y utiliza `backend/src/routes/customerRoutes.js`. La identidad, los programas, los tickets y las ventas son los mismos que usa la integración con Empresa.

`apps/customer/` conserva el trabajo previo de Expo para una posible etapa posterior. El desarrollo y la publicación de la app nativa están en pausa por decisión de producto del 3 de noviembre de 2026. No es necesario compilar Expo ni instalar una app para usar el portal.

Consulta [el alcance vigente](../docs/QORI_CUSTOMER.md).
