# Productos frecuentes

Al preparar una lista nueva, Elegir productos frecuentes abre los artículos de las listas anteriores del bolsillo y moneda seleccionados. Agrupa nombres equivalentes en mayúsculas, tildes y espacios; conserva las unidades distintas como productos separados. Permite buscar, seleccionar varios y ajustar cantidades. No representa existencias físicas.

El comprador elige entre usar el último precio real pagado como estimado o escribir sus propios estimados. Puede modificar cada importe o dejarlo pendiente. Se muestra la fecha y la unidad del precio de referencia. Los artículos ya presentes aparecen deshabilitados para evitar duplicados.

Solo se toma un precio de artículos marcados en listas PURCHASED cuyo movimiento sigue vigente, pagado y coincide en importe y moneda. Las ventas de Empresa se validan con la autorización canónica y el bolsillo; las ventas con devoluciones no aportan referencias. Se usa la fecha real del movimiento, no la fecha de creación de una lista posterior. Una lista sin pago confirmado nunca crea un último precio pagado.

La selección crea artículos nuevos, sin marcar ni precio real, y guarda la referencia elegida como estimado independiente. No modifica compras antiguas ni crea gastos. El selector está disponible al preparar el presupuesto; una vez iniciado Modo mercando se conserva el presupuesto original.

El catálogo se calcula a partir de registros privados existentes, sin tabla ni migración adicional. Validación con pruebas DOM, cálculos y API en QA aislado; revisión visual en navegador/móvil pendiente por indisponibilidad de la herramienta.
