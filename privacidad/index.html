Compromiso de privacidad

Sales Machine trata los datos personales con responsabilidad, proporcionalidad, seguridad y finalidad legitima. No vendemos bases de datos, no usamos datos del cliente para fines ajenos al servicio contratado y no hacemos uso indebido de la informacion. Esta politica explica que datos tratamos, para que los usamos, durante cuanto tiempo pueden conservarse y que derechos tienen los titulares.

1. Roles en el tratamiento

Sales Machine puede actuar como responsable del tratamiento respecto de datos de registro, facturacion, soporte, seguridad y relacion contractual con sus clientes. Tambien puede actuar como encargado del tratamiento respecto de datos de leads, compradores, afiliados, redenciones o usuarios finales que el cliente capture o gestione usando la plataforma. En ese caso, el cliente define la finalidad principal de su campana y debe contar con autorizaciones, avisos o bases legales aplicables.

2. Datos que podemos tratar

Podemos tratar datos de cuenta como nombre, empresa, NIT o cedula, correo, telefono, ciudad, direccion, credenciales protegidas, plan contratado, estado de pago y actividad dentro del portal. Tambien podemos tratar datos operativos como campañas, QR generados, tokens, redenciones, sedes, validadores, afiliados, ventas atribuidas, notas, preferencias, respuestas de formularios, medios de llegada, productos de interes e informacion necesaria para reportes.

No solicitamos datos sensibles salvo que el cliente los ingrese voluntariamente y bajo su responsabilidad. Recomendamos no cargar datos sensibles, de menores de edad, salud, biometria, orientacion politica, religion u otros datos especialmente protegidos salvo que exista base legal clara y medidas reforzadas.

3. Finalidades

Usamos datos para crear y administrar cuentas, validar accesos, procesar pagos, activar planes, entregar tickets QR, operar campanas, prevenir fraude, validar beneficios, generar reportes, medir resultados, prestar soporte, mejorar estabilidad, comunicar cambios del servicio, cumplir obligaciones legales y proteger la seguridad de la plataforma.

Los datos de usuarios finales se usan para operar la activacion o campana configurada por el cliente: registrar leads, asociar QR, validar beneficios, medir redenciones, relacionar compras, generar reportes y permitir seguimiento comercial por parte del cliente cuando tenga autorizacion para hacerlo.

4. No uso indebido ni venta de datos

Sales Machine no vende, alquila ni entrega bases de datos del cliente a terceros para marketing externo. No usamos los datos capturados por una empresa para favorecer a otra empresa. No contactamos leads del cliente para campañas propias ajenas al servicio, salvo que exista autorizacion expresa e independiente del titular y una finalidad informada.

5. Pagos y procesadores

Los pagos pueden procesarse mediante Mercado Pago u otros proveedores. Sales Machine no almacena numeros completos de tarjeta, codigos CVV ni credenciales bancarias. La autorizacion de tarjeta para cobro automatico se gestiona por el procesador de pago. Conservamos referencias de pago, estado, identificadores de transaccion, valores, fechas y metadatos necesarios para activar el servicio, soporte, conciliacion y auditoria.

6. Retencion de datos y cuentas inactivas

Mientras una cuenta mantenga pago activo, periodo vigente, obligaciones pendientes, soporte abierto o necesidad operativa razonable, Sales Machine puede conservar datos de cuenta, campañas, QR, leads, reportes y actividad para prestar el servicio contratado.

Cuando una cuenta quede inactiva, sin pago vigente o abandonada, Sales Machine podra limitar acceso y aplicar procesos de depuracion, anonimacion, minimizacion o eliminacion progresiva de datos que ya no sean necesarios. Esto protege a los titulares y evita conservar informacion sin finalidad activa. Algunos datos podran conservarse por obligaciones legales, fiscales, contables, antifraude, seguridad, defensa de reclamaciones o auditoria.

El cliente entiende que la conservacion completa del historial, leads, reportes y datos operativos esta asociada a cuentas activas o a periodos de retencion aplicables al plan. La suspension o cancelacion prolongada puede reducir disponibilidad de historiales, exportaciones o informacion no indispensable.

7. Seguridad

Aplicamos medidas razonables de seguridad tecnica y organizacional, incluyendo control de acceso, autenticacion, separacion por negocio, tokens, registros de actividad, proteccion de credenciales, buenas practicas de base de datos y revision de rutas sensibles. Ningun sistema es absolutamente infalible; por eso el cliente tambien debe proteger sus usuarios, contraseñas, dispositivos, permisos internos y exportaciones descargadas.

8. Acceso por usuarios del cliente

El cliente es responsable de asignar accesos solo a personas autorizadas y de retirar usuarios que ya no deban operar la cuenta. Las acciones realizadas por usuarios del cliente dentro del portal pueden quedar registradas para seguridad, trazabilidad y soporte.

9. Cookies, almacenamiento local y sesiones

El portal puede usar almacenamiento local del navegador para mantener sesion, preferencias de tema y estado de la interfaz. Cuando hay actualizaciones relevantes del portal, Sales Machine puede cerrar la sesion local y solicitar nuevo inicio de sesion para evitar errores de cache, pantallas cargando indefinidamente o inconsistencias entre frontend y backend.

10. Derechos de los titulares

Los titulares pueden solicitar acceso, actualizacion, rectificacion, supresion, prueba de autorizacion, revocatoria o informacion sobre el uso de sus datos, de acuerdo con la ley aplicable. Cuando los datos pertenezcan a leads o usuarios finales de una campaña de un cliente, Sales Machine podra orientar la solicitud hacia el cliente responsable de esa campaña, sin perjuicio de adoptar medidas razonables desde la plataforma cuando corresponda.

11. Encargados y proveedores

Podemos apoyarnos en proveedores de infraestructura, hosting, base de datos, analitica tecnica, correo, pagos, seguridad y soporte. Estos proveedores solo deben tratar datos para prestar servicios a Sales Machine y bajo condiciones razonables de confidencialidad, seguridad y finalidad.

12. Transferencias y ubicacion

La infraestructura o proveedores pueden ubicarse en paises distintos al del cliente. Al usar el servicio, el cliente autoriza el tratamiento y transferencia necesarios para operar la plataforma, siempre bajo medidas razonables y finalidades informadas.

13. Datos de menores

Sales Machine no esta diseñado para recolectar datos de menores sin autorizacion adecuada. Si una campaña pudiera involucrar menores, el cliente debe establecer reglas, autorizaciones y controles apropiados. Sales Machine podra eliminar o bloquear datos cuando detecte tratamiento indebido de menores.

14. Incidentes

Si se detecta un incidente de seguridad que comprometa datos personales, Sales Machine evaluara alcance, riesgos y medidas de mitigacion. Cuando sea legalmente exigible o razonablemente necesario, comunicara al cliente o a titulares afectados informacion relevante y acciones recomendadas.

15. Cambios de esta politica

Podemos actualizar esta politica por cambios legales, tecnicos, operativos o de seguridad. Cuando el cambio sea relevante, el portal podra solicitar nueva aceptacion o nuevo inicio de sesion. La version publicada indicara la fecha vigente.
